# NAVVAM Spices & Masalas

A polished multi-page catalogue and WhatsApp lead-generation website for NAVVAM Spices & Masalas — featuring 13 product pages, responsive design, accessible motion, product filters, call/WhatsApp actions, SEO metadata, and JSON-LD structured data.

## Tech Stack

- [TanStack Start](https://tanstack.com/start) — full-stack React framework
- [TanStack Router](https://tanstack.com/router) — type-safe file-based routing
- [Tailwind CSS v4](https://tailwindcss.com) — styling
- [Radix UI](https://www.radix-ui.com) — accessible component primitives
- [Bun](https://bun.sh) — package manager & runtime

## Development

Requires [Bun](https://bun.sh) or Node.js + npm.

```sh
git clone <this-repository-url>
cd navvam-spices
bun install
bun run dev
```

## Build

```sh
bun run build
bun run preview
```
